# Marque Planner dans le pilote web

Assets officiels du kit mosaïque, piste C, palette Récré, approuvés le 11 novembre 2026.
Source : dépôt marketing voisin, marketing/brand/logo/kit (maitres et web).
Les fichiers sont copiés sans modification ; leurs empreintes sont vérifiées dans choixMarque.test.js.

- Sans école : planner-horizontal.svg, ou planner-horizontal-fonce.svg sur fond sombre, au moins 120 px.
- Chez une école : logo ou nom de l’école, filet, planner-mot.svg (planner-mot-blanc.svg sur fond sombre). Aucun deuxième symbole.
- Capitales du mot à 40 % de la hauteur du logo d’école ; SVG mot de 108 unités, tracé des capitales de 100 unités.
- Le logo d’école repose sur une plaque blanche en mode sombre.
- Le favicon générique s’applique uniquement sans école ; le favicon d’école existant est conservé.
- Ni recoloration ni déformation du logo. Les couleurs de commande restent distinctes de celles du logo.

Le composant MarquePlanner applique cet assemblage. LogoEcole reste utilisé par les documents et surfaces hors pilote.
