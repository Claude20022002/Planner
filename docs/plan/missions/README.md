# Fiches de mission

Une fiche par mission donnée à un agent (Claude, Codex, agent de Cursor) par le **coordinateur** : [organisation.md](../organisation.md), § 10. Modèle : [../modeles/mission.md](../modeles/mission.md).

- Nom du fichier : l'identifiant de la fonction ou de l'étape, en minuscules (`pla-03b.md`).
- La fiche dit l'agent, la branche, le dossier de travail, **les fichiers qu'il peut écrire** et le prompt à lui donner.
- La vue d'ensemble est le tableau « Missions en cours » de [suivi.md](../suivi.md).
- Une mission close garde sa fiche, avec la date et le verdict de la dernière relecture.

Aucune fiche n'existe pour les travaux commencés avant le 15 novembre 2026 : leur état est dans leur fiche de session.
